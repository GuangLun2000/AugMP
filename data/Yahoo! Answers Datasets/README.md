# Yahoo! Answers Datasets

Links: [yassiracharki/Yahoo_Answers_10_categories_for_NLP](https://huggingface.co/datasets/yassiracharki/Yahoo_Answers_10_categories_for_NLP)

Paper: [Character-level Convolutional Networks for Text Classification](https://arxiv.org/abs/1509.01626)

The dataset is downloaded automatically on first use (`dataset='yahoo_answers'` in `main.py`) and cached in `data/Yahoo_Answers_Datasets/`. To use your own copy instead, place `train.csv` and `test.csv` here (no header; columns: label 1–10, text).
